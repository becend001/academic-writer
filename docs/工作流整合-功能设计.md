# 工作流整合 — 功能详细设计

## 一、功能概述

### 1.1 功能定位

**名称**：一键全流程

**定位**：让用户上传一篇论文，自动完成润色→翻译→摘要→关键词的完整流程

**核心价值**：
- 用户不需要手动逐个操作
- 一次上传，自动完成所有处理
- 节省时间，提高效率

### 1.2 与现有功能的区别

| 功能 | 现有设计 | 工作流设计 |
|------|----------|------------|
| **操作方式** | 手动逐个点击 | 一键自动执行 |
| **处理顺序** | 用户自己决定 | 系统自动编排 |
| **结果展示** | 单独显示 | 汇总显示 |
| **导出** | 复制单个结果 | 导出完整文档 |

### 1.3 用户场景

```
场景1：论文润色全流程
用户：上传论文 → 自动润色 → 自动翻译 → 自动摘要 → 导出完整文档

场景2：课题申报全流程
用户：输入研究想法 → 生成选题 → 生成大纲 → 逐章节生成 → 导出申报书

场景3：文献综述
用户：输入研究主题 → 搜索文献 → 生成综述 → 导出文档
```

## 三、技术实现

### 3.1 工作流定义

```typescript
interface WorkflowStep {
  id: string;
  name: string;
  action: string;        // API调用
  options?: any;         // 参数
  dependsOn?: string[];  // 依赖的步骤
}

interface Workflow {
  id: string;
  name: string;
  description: string;
  steps: WorkflowStep[];
}

// 论文润色全流程
const polishWorkflow: Workflow = {
  id: "polish-full",
  name: "论文润色全流程",
  description: "上传论文 → 润色 → 翻译 → 摘要 → 导出",
  steps: [
    { id: "polish", name: "润色", action: "/api/polish" },
    { id: "translate", name: "翻译", action: "/api/translate", dependsOn: ["polish"] },
    { id: "abstract", name: "摘要", action: "/api/abstract", dependsOn: ["polish"] },
    { id: "keywords", name: "关键词", action: "/api/keywords", dependsOn: ["polish"] },
  ],
};
```

### 3.2 工作流引擎

```typescript
class WorkflowEngine {
  private workflow: Workflow;
  private currentStep: number = 0;
  private results: Record<string, any> = {};
  private status: "idle" | "running" | "paused" | "completed" | "error" = "idle";

  async start(inputText: string) {
    this.status = "running";
    
    for (const step of this.workflow.steps) {
      // 检查依赖
      if (step.dependsOn) {
        const depsMet = step.dependsOn.every(dep => this.results[dep]);
        if (!depsMet) continue;
      }
      
      // 执行步骤
      const result = await this.executeStep(step, inputText);
      this.results[step.id] = result;
      
      // 更新进度
      this.currentStep++;
    }
    
    this.status = "completed";
    return this.results;
  }

  private async executeStep(step: WorkflowStep, input: string): Promise<any> {
    const res = await fetch(step.action, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ text: input, ...step.options }),
    });
    return res.json();
  }
}
```

### 3.3 导出功能

```typescript
// 导出为Markdown
export function exportToMarkdown(results: Record<string, any>): string {
  let md = "# 论文处理结果\n\n";
  
  if (results.polish) {
    md += "## 润色结果\n\n" + results.polish.polishedText + "\n\n";
  }
  if (results.translate) {
    md += "## 翻译结果\n\n" + results.translate.translatedText + "\n\n";
  }
  if (results.abstract) {
    md += "## 摘要\n\n" + results.abstract.abstract + "\n\n";
    md += "## 关键词\n\n" + results.abstract.keywords.join("、") + "\n\n";
  }
  
  return md;
}

// 导出为TXT
export function exportToTxt(results: Record<string, any>): string {
  return exportToMarkdown(results).replace(/#/g, "").replace(/\*\*/g, "");
}

// 下载文件
function downloadFile(content: string, filename: string, type: string) {
  const blob = new Blob([content], { type });
  const url = URL.createObjectURL(blob);
  const a = document.createElement("a");
  a.href = url;
  a.download = filename;
  a.click();
  URL.revokeObjectURL(url);
}
```

## 六、总结

**工作流整合**是一个高效率功能，它：

1. **节省时间** — 一次点击，自动完成所有处理
2. **提升体验** — 不需要手动操作多个步骤
3. **方便导出** — 一键导出完整文档
4. **差异化明显** — DeepSeek做不到这个

**这个功能会让用户觉得："用这个工具比手动操作快多了！"**
