## 一、产品概述

### 1.1 产品定位

AI学术写作助手是专为中国高校教师设计的AI驱动学术写作平台，提供论文润色、翻译、摘要生成、文献搜索、课题申报辅助等功能，帮助高校教师高效完成学术写作任务。

### 1.2 目标用户

- **主要用户**：中国高校教师（约200万人）
- **次要用户**：博士生、科研人员、学术编辑
- **使用场景**：论文投稿前润色、课题申报书撰写、文献综述撰写

### 1.3 技术架构

| 层级 | 技术选型 |
|------|----------|
| 前端 | Next.js 16 (App Router) + React + TypeScript |
| UI框架 | Tailwind CSS + 自定义设计系统 |
| 后端 | Next.js API Routes |
| 数据库 | Supabase (PostgreSQL) |
| AI引擎 | DeepSeek API |
| 文献数据 | Semantic Scholar API |
| 认证 | Supabase Auth (邮箱密码) |
| 进程管理 | PM2 |
| 部署 | 阿里云轻量应用服务器 |

### 2.2 核心AI功能（工作台）

#### 2.2.1 论文润色

- **功能**：对中文学术文本进行专业润色
- **AI Prompt**：20年经验学术编辑专家人设，包含润色原则、修改标准、常见修改示例
- **输出**：润色后文本 + 修改列表（原文→修改后→原因）
- **限制**：单次输入不超过5000字
- **前后对比**：支持原文vs润色后的对比视图

#### 2.2.2 学术翻译

- **功能**：中英双向学术翻译
- **AI Prompt**：学术翻译专家人设，区分中→英和英→中两种模式
- **中→英**：SCI/SSCI期刊写作风格，被动语态、名词化表达
- **英→中**：国内学术界通用中文术语，避免翻译腔
- **限制**：单次输入不超过5000字

#### 2.2.3 摘要生成

- **功能**：根据论文内容生成结构化摘要和关键词
- **AI Prompt**：摘要撰写专家，按结构（背景→目的→方法→结果→结论）生成200-300字摘要
- **输出**：摘要文本 + 5-8个关键词
- **限制**：单次输入不超过20000字

### 2.3 一键全流程

提供3条自动化工作流，每条流程包含多个AI处理步骤，结果分Tab展示：

#### 2.3.1 论文润色全流程

| 步骤 | 内容 | 说明 |
|------|------|------|
| 第1步 | 润色 | 原文vs润色后对比展示 |
| 第2步 | 英文翻译 | 将润色后文本翻译为学术英语 |
| 第3步 | 摘要生成 | 生成中英文摘要和关键词 |
| 导出 | Markdown / 文本文件 | — |

**输入界面**：大文本框 + 说明文字 + "开始润色"按钮

#### 2.3.2 课题申报全流程

| 步骤 | 内容 | 说明 |
|------|------|------|
| 第1步 | 选题推荐 | AI推荐3个选题，每个含标题、研究意义、创新点、可行性、预期成果 |
| 第2步 | 写作大纲 | 生成标准课题申报书大纲（7大章节） |
| 第3步 | 章节要点 | 每个章节的写作要点和建议字数 |
| 导出 | Markdown / 文本文件 | — |

**输入界面**：研究领域（必填）+ 关键词（选填）+ 项目类型下拉框 + "生成选题方案"按钮

**项目类型**（17个，分5组）：
- 国家自然科学基金：面上、青年、重点、重大项目
- 国家社会科学基金：一般、青年、重点项目
- 教育部项目：人文社科一般、青年、重点项目
- 省部级项目：省自然科学基金面上/青年、省社科基金面上/青年、省教育厅/科技厅
- 其他：市厅级、横向课题、校级科研、博士后科学基金

#### 2.3.3 文献综述全流程

| 步骤 | 内容 | 说明 |
|------|------|------|
| 第1步 | 关键词与文献 | AI生成英文检索关键词，Semantic Scholar搜索真实文献 |
| 第2步 | 综述框架 | 基于搜索到的文献生成综述写作框架 |
| 第3步 | 写作要点 | 每个部分的写作要点和建议字数 |
| 导出 | Markdown / 文本文件 | — |

**输入界面**：研究主题（必填）+ 研究领域（选填）+ "开始检索文献"按钮

### 2.4 智能写作引导

- **输入**：研究领域、关键词、研究想法、项目类型
- **输出**：AI推荐选题 → 写作大纲 → 各章节要点
- **特点**：单次AI调用生成完整方案，适合快速了解课题申报框架

### 2.5 课题申报助手

独立的课题申报工作台，分3步向导：

1. **选题阶段** — 输入研究领域+关键词，AI推荐3-5个选题
2. **信息填写** — 项目名称、研究领域、关键词、项目类型（17个选项）
3. **分章节编辑** — 8个章节独立生成：
   - 摘要、立项依据、研究内容、研究方案、特色创新、年度计划、预期成果、经费预算
   - 每个章节可独立AI生成、复制、导出

### 2.6 文献搜索

- **关键词搜索** — 调用Semantic Scholar API，支持年份筛选
- **AI推荐** — 输入文本，AI提取关键词后搜索相关文献
- **文献综述生成** — 选中文献，生成4种聚焦模式的综述（研究现状/方法/趋势/自定义）
- **引文生成** — 支持6种格式：GB/T 7714、APA、MLA、Chicago、IEEE、Harvard
- **论文选择** — 多选文献进行批量操作

### 2.7 文件上传

- **支持格式**：PDF、Word (.doc/.docx)、TXT
- **大小限制**：10MB
- **交互方式**：拖拽上传 + 点击上传
- **处理**：PDF用pdf-parse解析，Word用mammoth解析

### 2.8 个人中心

- **用户信息** — 邮箱、注册时间、当前套餐
- **使用统计** — 今日使用次数/3、累计使用次数
- **最近文档** — 最近5条保存的文档记录
- **账号设置** — 修改密码、退出登录
- **管理员入口** — 白名单管理（仅管理员可见）

### 2.9 新手引导

- **触发条件** — 首次访问工作台（localStorage检测）
- **引导内容** — 5步骤弹窗引导，介绍润色、翻译、摘要、文献搜索、课题申报
- **只显示一次** — 后续访问不再弹出

## 五、数据库设计

### 5.1 saved_works 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID (PK) | 主键 |
| user_id | UUID (FK) | 用户ID，关联auth.users |
| title | TEXT | 文档标题 |
| content | TEXT | 原始内容 |
| result | TEXT | AI处理结果 |
| feature | TEXT | 功能标识（polish/translate/abstract等） |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |

- **RLS策略**：`auth.uid() = user_id`，用户只能读写自己的数据
- **用途**：文档保存 + 使用量统计（按user_id和created_at统计）

### 5.2 whitelist 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID (PK) | 主键 |
| email | TEXT (UNIQUE) | 用户邮箱 |
| created_by | TEXT | 添加者邮箱 |
| created_at | TIMESTAMPTZ | 创建时间 |

- **用途**：白名单用户不受每日使用次数限制
