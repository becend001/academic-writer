# 智能写作引导 — 功能详细设计

## 一、功能概述

### 1.1 功能定位

**名称**：智能写作引导

**定位**：帮助没有思路的用户，从研究想法到完整写作方案的一站式引导工具

**核心价值**：
- 解决"不知道写什么"的核心痛点
- 提供从想法到框架的完整路径
- 比DeepSeek更专业、更完整

### 1.2 目标用户

| 用户类型 | 场景 | 需求 |
|----------|------|------|
| **课题申请者** | 想申请课题，但不知道写什么方向 | 选题建议+申报框架 |
| **论文写作者** | 有研究想法，但不知道怎么组织 | 论文大纲+各章节要点 |
| **开题报告者** | 需要写开题报告 | 报告框架+内容要点 |
| **文献综述者** | 需要写文献综述 | 综述结构+写作指导 |

### 1.3 功能入口

**位置**：课题申报模块内，选题建议之后

**流程**：
```
课题申报 → 选题建议 → 选择选题 → 智能写作引导 → 撰写申报书
```

## 三、技术实现

### 3.1 API设计

```typescript
// /api/grant/guide
POST /api/guide

Request:
{
  "field": "人工智能",           // 研究领域（必填）
  "keywords": "深度学习, 医学影像", // 关键词（选填）
  "idea": "我想研究AI在医学影像中的应用", // 研究想法（选填）
  "projectType": "国自然面上项目", // 项目类型
  "outputType": ["topics", "outline", "points"] // 输出内容类型
}

Response:
{
  "topics": [...],      // 推荐选题
  "outline": {...},     // 写作大纲
  "points": {...}       // 各章节要点
}
```

### 3.2 Prompt设计

```typescript
const guidePrompt = `你是一位资深的科研项目申报专家和学术写作导师。请根据用户的研究想法，生成完整的写作方案。

用户信息：
- 研究领域：${field}
- 关键词：${keywords}
- 研究想法：${idea || "未提供"}
- 项目类型：${projectType}

请生成以下内容：

1. 推荐选题（3个）
   每个选题包含：
   - 项目名称
   - 研究意义
   - 创新点
   - 可行性分析
   - 预期成果

2. 写作大纲
   按照${projectType}的标准格式，包含：
   - 一、立项依据（研究背景、国内外研究现状、研究意义）
   - 二、研究内容（研究目标、研究内容、关键问题）
   - 三、研究方案（技术路线、实验方案、可行性分析）
   - 四、特色与创新
   - 五、年度计划
   - 六、预期成果
   - 七、经费预算

3. 各章节要点
   为每个章节提供：
   - 需要包含的要点（3-5个）
   - 每个要点的简要说明
   - 建议字数

请以JSON格式输出，包含topics、outline、points三个字段。`;
```

### 3.3 数据结构

```typescript
interface WritingGuide {
  topics: Array<{
    title: string;           // 选题名称
    significance: string;    // 研究意义
    innovation: string;      // 创新点
    feasibility: string;     // 可行性
    expectedOutput: string;  // 预期成果
  }>;
  
  outline: {
    sections: Array<{
      id: string;
      title: string;
      subsections?: Array<{
        id: string;
        title: string;
      }>;
    }>;
  };
  
  points: Record<string, {
    title: string;
    items: Array<{
      point: string;
      description: string;
    }>;
    suggestedWords: number;
  }>;
}
```

## 九、总结

**智能写作引导**是一个高价值功能，它：

1. **解决核心痛点** — 用户不知道写什么
2. **提供完整方案** — 从想法到框架一步到位
3. **差异化明显** — DeepSeek做不到这个
4. **使用频率高** — 每次写新课题都需要

**这个功能会让用户觉得："这个工具比直接用DeepSeek好用多了！"**
